# Pilot outreach pack

Use with [`pilot-loi-template.md`](./pilot-loi-template.md) after staging is live.

---

## ICP (ideal design partner)

- Canadian incorporated SME, **$500K–$5M** revenue
- Pays overseas suppliers/contractors (US, MX, PH, etc.)
- Pain: wire fees, FX spread, slow settlement, no approval workflow
- Has owner/controller who can complete KYC and approve payments

---

## Offer summary

| Item | Value |
|------|-------|
| Duration | 90 days |
| Fee | 1% per payment (pilot: 0.5% optional) |
| Volume cap | $50,000 CAD/month |
| Support | White-glove Interac confirm + onboarding call |
| Settlement | Circle sandbox → production per counsel timeline |

## Demo script (15 min)

1. Marketing quote at `/` — live FX estimate  
2. Register → org created  
3. KYC submit → you approve live  
4. Interac deposit instructions → explain manual confirm SLA  
5. Send payment → approver flow if over threshold  
6. Audit trail + optional @VIRLUXBOT alert
